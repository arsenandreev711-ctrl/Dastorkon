# Dastorkon — запуск

Сайт состоит из двух частей:
- `schema.sql` — база данных, права доступа и правила заказа;
- `index.html`, `app.js`, `styles.css`, `config.js`, `_redirects` — сам сайт (статические файлы, сервер не нужен).

Адреса на сайте:
- `/t/КОД` — меню гостя для стола (эту ссылку записывают на NFC-метку);
- `/cabinet` — кабинет ресторана;
- `/admin` — панель платформы (вы).

## 1. База в Supabase (5 минут)

1. Supabase → ваш проект → **SQL Editor** → **New query**.
2. Вставьте весь файл `schema.sql` и нажмите **Run**. Должно быть «Success. No rows returned».
3. **Project Settings → API** (или **Data API**): скопируйте **Project URL** и **anon public** ключ.
   Ключ `service_role` никуда не вставляйте.
4. Откройте `config.js` и вставьте их вместо `YOUR-PROJECT` и `YOUR-ANON-KEY`.
   Там же укажите свой телефон поддержки и цены тарифов.

## 2. Сайт в интернете (5 минут)

Вариант А, через GitHub (удобно обновлять):
1. Создайте на GitHub репозиторий `nfc-menu` и загрузите в него содержимое этой папки.
2. Netlify → **Add new site → Import an existing project → GitHub** → выберите репозиторий.
3. Build command и Publish directory оставьте пустыми. **Deploy**.

Вариант Б, без GitHub: Netlify → **Add new site → Deploy manually** → перетащите папку с файлами сайта.

Сайт получит адрес вида `nfc-menu.netlify.app`. Свой домен: Netlify → **Domain management → Add domain**.

## 3. Настройка входа (2 минуты)

Supabase → **Authentication → URL Configuration**:
- **Site URL** = адрес сайта, например `https://nfc-menu.netlify.app`;
- в **Redirect URLs** добавьте тот же адрес с `/**` в конце.

Иначе ссылка из письма для подтверждения email будет вести не туда.

## 4. Первый вход (сразу после публикации)

1. Откройте `/admin`, нажмите «У меня нет аккаунта», зарегистрируйтесь своим email, подтвердите письмо, войдите.
2. Нажмите **«Стать администратором»**. Это работает только один раз: первый нажавший получает полный доступ, поэтому сделайте это сразу.

## 5. Подключение ресторана

1. `/admin` → **Рестораны** → название → **Подключить** (14 дней бесплатно).
2. **NFC-метки** → выберите ресторан → количество столов → **Выпустить метки**.
3. Владелец ресторана регистрируется на `/cabinet` своим email.
4. `/admin` → **Доступы** → ресторан, его email, роль «Владелец» → **Выдать доступ**.
5. Владелец в кабинете: **Блюда и цены** (категории, блюда, фото), **Столы и NFC** (кнопка «+ Стол» сама берёт свободную метку), **Заведение** (фото интерьера, логотип, сотрудники).

## 6. Запись NFC-меток

Метки NTAG213 или NTAG215. На телефоне приложение **NFC Tools** (Android и iPhone):
Write → Add a record → URL/URI → вставьте ссылку стола из кабинета → Write → приложите метку.
Проверьте: телефон у метки должен открыть меню нужного стола.
После проверки метку можно защитить от перезаписи (Other → Lock tag), но это необратимо.

## Что пока не подключено

- **Онлайн-оплата.** Гость выбирает «оплатить официанту», официант отмечает оплату в кабинете.
  Для онлайн-оплаты нужна серверная функция с ключами вашего платёжного провайдера.
- **r_keeper.** Заказы приходят в кабинет (с звуком). Передачу в r_keeper подключаем через дилера.
- **Тариф Supabase.** Бесплатный проект засыпает после недели без активности. Для работающих ресторанов нужен Pro ($25/мес).
